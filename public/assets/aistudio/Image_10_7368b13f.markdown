## Brand & Style

The design system establishes a high-performance, dark-mode engineering aesthetic built for modern clean-energy infrastructure in Odisha, India. It positions solar energy not merely as an ecological alternative, but as an advanced technological investment with calculated returns and institutional reliability.

The visual style blends **technical minimalism** with **restrained glassmorphism**:
- Deep void backdrops anchor the interface in precision and durability.
- Kinetic emerald illumination commands decisive action across telemetry, savings calculators, and e-commerce flows.
- Metallic solar gold provides focused cues for monetary yields, government subsidies (PM Surya Ghar / Odisha state incentives), and premium tier badges.
- Glass panels with razor-thin luminescence define spatial containment without visual clutter, maintaining strict legibility in high-ambient-light field conditions.

## Colors

The color architecture is built for ultra-high contrast dark interfaces:

- **Primary (`#10B981`) & Deep Emerald (`#059669`):** Represents generative electrical power, operational health, active generation telemetry, and conversion targets.
- **Secondary (`#F59E0B`):** Denotes monetary value, subsidy calculations, peak sun-hour tracking, and warranty certifications.
- **Base Surfaces (`#0B0F12` and `#12181F`):** Rich, dark charcoal-black substrates that eliminate screen glare and reduce eye fatigue for engineers and consumers.
- **Border Glass (`rgba(255, 255, 255, 0.08)`):** Provides crisp structural edge definition without weight.
- **Solar Flare (`#F27D26`):** Reserved strictly for critical peak warnings, photovoltaic heat warnings, and high-impact regional alerts.

## Typography

Typography is calibrated across three distinct roles:
1. **Space Grotesk (Headings & Display):** Imparts an engineered, geometric precision ideal for technical declarations, capacity ratings, and product titles.
2. **Inter (Body & Narrative):** Offers neutral legibility for documentation, equipment specifications, and commercial terms.
3. **JetBrains Mono (Telemetry, Financials, & Data Labels):** Renders all energy generation readouts (kWh/MWh), pricing (₹ INR), panel dimensions, efficiency percentages, and code identifiers.

## Layout & Spacing

A mobile-first fluid layout architecture built on an 8pt spatial grid:

- **Mobile (< 768px):** Single-column stack with `1rem` safe-edge margins. Telemetry panels, calculators, and system architecture breakdowns collapse into vertical stepped flows.
- **Tablet (768px - 1024px):** 8-column layout with `1.5rem` gutters and `2rem` outer margins.
- **Desktop (1024px+):** 12-column layout capped at `1280px` max-width, maintaining centered orientation with `1.5rem` gutters and `3rem` exterior canvas offsets.

Section vertical rhythm maintains `space-xl` internally between modules and `space-2xl` between macro narrative blocks.

## Elevation & Depth

Visual hierarchy uses a layered glassmorphic surface-container model:

1. **Canvas (Lowest Layer):** `#0B0F12` pitch base. Non-interactive.
2. **Surface Low (`#12181F`):** Solid background container for large layout sections, comparison tables, and static content blocks.
3. **Surface Glass (`rgba(18, 24, 31, 0.75)` with `12px` backdrop blur):** Floating modules, interactive equipment cards, and calculation wizards. Enclosed by a 1px border (`rgba(255, 255, 255, 0.08)`).
4. **Interactive Hover Elevation:** Surface tint lightens to `rgba(26, 34, 44, 0.85)` with a targeted ambient glow: `box-shadow: 0 10px 30px -10px rgba(16, 185, 129, 0.15)`.
5. **Modal & Floating Overlays:** Deepest z-index blur (`backdrop-blur-md`, `rgba(11, 15, 18, 0.85)`) framed with crisp 1px borders and elevated by a dual shadow: `0 20px 40px -15px rgba(0, 0, 0, 0.7)`.

## Shapes

The design system uses **Soft (`1`)** geometry:
- Base controls, buttons, form inputs, and metric chips maintain a compact `0.25rem` (4px) corner radius.
- Cards, modal containers, and dashboard tiles use `0.5rem` (8px).
- Large technical hero containers and diagram frames max out at `0.75rem` (12px).

Avoid high pill radii and circular forms outside of status indicator dots. The crisp 4px/8px corners emphasize engineering discipline and structural rigidity.

## Components

### Buttons
- **Primary Action (Energy Emerald):** Solid background `#10B981`, text `#0B0F12`, font weight 600. Hover transitions to `#059669` with an emerald glow (`0 0 20px rgba(16, 185, 129, 0.3)`).
- **Secondary (Solar Gold Accent):** Border 1px solid `#F59E0B`, text `#F59E0B`, transparent background. Used exclusively for "Calculate ROI", "Download Subsidy Sheet", and financial estimates.
- **Glass / Ghost:** Background `rgba(255, 255, 255, 0.04)`, border 1px solid `rgba(255, 255, 255, 0.08)`, text `#F8FAFC`.

### Chips & Telemetry Badges
- Constructed with `JetBrains Mono` label-md typography.
- Status chips: `4px` padding inline, background `rgba(16, 185, 129, 0.1)`, text `#10B981`, border 1px solid `rgba(16, 185, 129, 0.25)`. A 6px pulsing dot accompanies live system grid metrics.

### Input Fields & Calculation Sliders
- **Inputs:** Dark field `#0B0F12`, border 1px solid `rgba(255, 255, 255, 0.12)`, text `#F8FAFC`, placeholder `#64748B`. Focused state engages 1px border `#10B981` without browser-native rings.
- **Load / Kilowatt Range Sliders:** Track height 4px in `#12181F`, active progress bar filled in `#10B981`, slider thumb 16px square with `2px` roundedness and `#F8FAFC` fill.

### Cards & Grid Containers
- Translucent backdrop blur `rgba(18, 24, 31, 0.75)` with 1px border `rgba(255, 255, 255, 0.08)`.
- Internal layout features strict 24px padding (`space-lg`), separating headline specifications from performance output graphs.

### Checkboxes & Radios
- Square forms (`2px` radius) with `1.5px` border in `#64748B`. Checked state fills `#10B981` with dark glyph `#0B0F12`.

### Domain-Specific Components
- **Inverter & Photovoltaic Spec Matrix:** Dense, monospaced tabular layouts contrasting tier levels (Mono PERC vs. TOPCon).
- **Subsidy Calculator Stepper:** Interactive visual meter displaying real-time central and Odisha state solar grants against upfront system cost.
